# Линия 0

Риалтайм на Харде. Максимально объективная и фактическая реальность, какая
есть: чистая физика + жизнь в её форме.

## Точка отсчёта

Линия 0 — точка отсчёта для всей концепции:

- **НАД** надстраивается над ней: архитектура смыслов и практик.
- **ПОД** — погружения сознания из неё, с возвратом на линию 0.

## Позиционирование и узоры

- Линия 0 — линия всей жизни на Харде: по ней можно позиционироваться (где ты
  на линии). Ноль/0 — непосредственно момент «сейчас» и каждый раз центр НАД
  (см. «Свёрнутый-НАД»).
- В НАД та же линия, но из сферы: может заворачиваться в узоры — в зависимости
  от ритмов/циклов. Это проекция, а не другое пространство: начало координат
  не меняется.
