# Ось когнитивности

- Простая жизнь: малый скрытый объём → малая вариативность → высокая
  устойчивость.
- Когнитивная жизнь (животное → человек → ASI): больше скрытого объёма →
  больше ПОДов и предиктов, больше путей обходить непосредственный Хард →
  больше свободы, но больше цена ошибки согласования.
- Рост когнитивности = рост расстояния между видимой формой и внутренним
  объёмом, который форма должна научиться удерживать.
