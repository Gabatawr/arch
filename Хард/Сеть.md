# Сеть

Левельность как разметка: узлы с глубинами точности, на которые можно что-то
закрепить.

- **Сеть — левельность**: разметка как сеть узлов с глубинами точности, на
  которые можно что-то закрепить.
- Из цепи взаимодействий выстраиваются сети высшие — кровеносная, интернет:
  попытка закрыть все дыры. Сеть по большей части статична; динамика уже в ней.
- Биология и Матрица — тоже сети: одна содержит жизнь, другая — абстракцию
  представлений/данных. Мозг строит сеть мировоззрения, постоянно синхронизируя
  её с Хардом. Сети могут меняться, развиваться, эволюционировать.
- Быть в сети — не метафора: доступ идёт по живым, которые рядом в свой период.
  Кто выпал из сети в своё окно — теряет дверь: окно закрывается.
- Приватность при этом держится: двери общие, а за ними своё («Софт»: иерархия
  приватности).

## Сшивки

- Двери — доступ идёт по сети: узлы, на которые дверь закрепляется.
- Душа — наибольшая сеть живого: та же разметка, но с максимальным охватом.
- Софт — за дверями общее, а приватность держится иерархией консенсусов.
- Матрица — сеть абстракции против сети жизни.
