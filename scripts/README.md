# scripts

Служебное: сборка архива и проверка протокола статусов. Сами тексты — в
`Хард/`, `НАД/`, `ПОД/`; служебные (`00-`…`03-`) — в корне.

## Что здесь

| файл | что делает |
|---|---|
| `merge.py` | собирает темы в `README.md` (полная сборка) и в `Игнор/склейки/` (по группам) |
| `audit_status.py` | проверяет протокол статусов — раздел «Статусы» в `00-индекс.md` |
| `git-hooks/pre-commit` | пересобирает `README.md` перед каждым коммитом |
| `install-hooks.sh` | ставит хуки из `git-hooks/` в `.git/hooks` (на новой машине) |

Сгенерированного здесь нет: склейки уходят в `Игнор/склейки/` (папка `Игнор/`
в `.gitignore` и в сборку не попадает). Мусор в `scripts/` не копится.

Порядок сборки задан в `merge.py`: служебные → `Хард` → `НАД` → `ПОД`, внутри
папки свод первым, дальше по алфавиту, подпапки раскрываются на своём месте.
Руками `README.md` не правится — только выше маркера (шапка).

## На новой машине

    git clone <репозиторий> arch && cd arch
    sh scripts/install-hooks.sh             # хуки из git-hooks/ в .git/hooks
    python3 scripts/merge.py --dry-run      # план сборки, ничего не пишет
    python3 scripts/audit_status.py         # 0 нарушений — протокол цел

Нужен только `python3` (3.8+), без зависимостей и пакетов.

## Проверки

`audit_status.py` ловит: статус вне списка, две статус-строки в карточке,
пометку не из списка статусов, «закрыто + остаток» внутри одной записи `03`,
длину строки вне таблиц (только предупреждение). Код возврата: 0 — чисто.
