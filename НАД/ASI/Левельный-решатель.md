# Левельный решатель

Внешнее наблюдение (не наша механика): слой, который не порождает текст, а
принимает материал и возвращает типизированные решения с вероятностями
(реализация — Jev). Для архива важен как **исполнимая
форма** того, что у нас записано взглядом: факт в точке, истина в зоне; рамка
и допуск. Сошлось по всем шести законам «Оптики допуска» — это и есть
ценность, остальное вторично.

## Как устроен

Один запрос = материал (`state`) + набор вопросов (`questions`). Имена
вопросов метод не видит: они для кода, не для модели.

| Тип вопроса | Спрашивает | Возвращает |
|---|---|---|
| Выбор | который из вариантов | выбранный, распределение, уверенность |
| Уровень | на каком уровне шкалы | положение, легенду, распределение, уверенность |
| Да/нет | верно ли | одно число 0…1 |

- **Вопрос — рамка**: вырезает зону попадания из возможного, ответ — коллапс
  внутри неё. Значение извне объявленных вариантов не появится.
- **Ответ — допуск, а не точка**: не одно значение, а распределение по зоне.
- **Уверенность** — не отдельное предсказание, а сводка формы распределения:
  пик на одном варианте — высокая, размазано — низкая.
- **Вопросы независимы**: ответ одного не контекст для другого; вместе их
  считают параллельно, добавление вопроса почти не меняет времени.
- Материал текстовый; вопрос можно навести на часть состояния по имени.

## Как механика

- **Удержание против раннего коллапса.** На иерархии решатель идёт по
  уровням: дети узла — один вопрос, ответ выбирает, чьи дети идут дальше.
  Жадный проход берёт лучшего ребёнка и выбрасывает остальных — одна ранняя
  ошибка не восстанавливается (машинная ложная определённость). Удержание
  несколькими путями держит несколько лучших веток, спрашивает каждую границу
  параллельно и режет по среднему геометрическому вероятностей (нормировка по
  длине): глубокая ветка переигрывает неверный ранний выбор, а расхождение
  лучшей и второй ветки — мера ясности: близко к единице — размыто (Ночь),
  велико — ясно (День). Это движение огня по сетке точностей: просадки не
  переспрашивают, неопределённое держат открытым, пока не появится глубина.
- **Зона ожидания — холст.** Якоря во многом известны, остальное неявно;
  решатель выкладывает вероятностную карту по объявленным рамкам, а сама
  расстановка — акт, и он за живым.
- **Порог действия — мера правды в точке.** Ниже порога «не знаю» — сигнал, а
  не отказ; порог зависит от цены ошибки (разрушительное гейтится выше, чем
  чтение).
- **Калибровка — по группам, не по ответу.** «Уверенность 1.0» описывает
  форму его же ответа, а не правильность; пороги и веса целиком на живом.
- **Материал** не враждебен по умолчанию, но текст, написанный чтобы сдвинуть
  ответ, может его сдвинуть — это наш дым.
