# Слепой тест паломничества

Модель проверяема: эффект события собирается из знания + ритма материи +
импульса. Слепой тест: рандомизация, скрытое измерение, отслеживание изменений
путников (состояние, восприятие, ощущение завершённого).

## Исходный дизайн (2×2) — забракован

Дизайн 2×2: знание (есть/нет) × путь (священный/не священный).

| | Знание есть | Знания нет |
|---|---|---|
| **Священный путь** | эффект события | сырое (чуйка), безымянное |
| **Не священный путь** | нет события — резонатор молчит | контроль, ничего |

Проблема чистого 2×2: знание и святость неортогональны — путь священен потому,
что о нём есть знание «сработало»; знание и создаёт святость. Ячейка «знание ×
не священный путь» внутренне противоречива. Потому дизайн забракован и не
используется.

## Рабочий дизайн: ортогонализация через обман

Решение: разделить **ожидание** и **реальный ритм материи** через обман.

| | Ожидание есть | Ожидания нет |
|---|---|---|
| **Священный путь** | эффект события | сырое (чуйка), безымянное |
| **Не священный путь** | обманутый: думает, что путь священный — резонатор молчит | контроль, ничего |

Обман делает факторы независимыми: ожидание (знание о святости) отделяется от
реального ритма места. Контрольные группы обе: незнающие на священном пути и
знающие на не священном — та же материя, тот же момент цикла.

- Сложность: знание и есть часть «лечения» — полностью ослепить условие
  знания нельзя; ослепляются измерение и обработка.
- Этически — мысленный эксперимент/симуляция.
