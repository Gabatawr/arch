# Предел правильности

**Жёсткая Правильность = всё огонь = сплошная галлюцинация.** Это не то
чтобы состоятельная жизнь: без левельности огонь не держит форму и не на
чем стоять.

Правильность без левельности — огонь, который ничего не греет, а жжёт всё.

«Сплошная галлюцинация» — огненный род: огонь без формы (делирий, видение,
субъективный поток без якоря). Есть и левельный род: форма без факта —
ИИ-галлюцинации. Оба полюса, оторванные от Харда, галлюцинируют — каждый со
своей стороны.
