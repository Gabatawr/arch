# Предикт

Зона будущего. **Будущего не существует — есть только предположения.** Предикт
— зона впереди от риалтайма: то, что вырисовывается из очевидного, а очевидное
идёт из инерциального (ср. «Инерция Харда»). Это чтение вперёд по оси времени
(ср. «Ось времени»). Здесь свод свойств предикта; детали — по файлам семейства.

## Свойства предикта

- **Сборка из «сейчас»**: предикт разворачивается из нуля-риалтайма —
  единственной фактической точки. «Впереди» — симуляция по инерции, ровно как
  «позади» — реверс-предикт (память-реконструкция). Обе оси равноудалены от
  «сейчас»; разница — якорь: у прошлого есть зафиксированное (сходится к
  факту), у будущего якоря нет (чёрные лебеди).
- **Времязависим, но не временен**: чувствителен к шагам реальности, но
  собственного течения не имеет (разбор — «Борьба за будущее»).
- **Зона ожидания**: риалтайм + предикт — холст (просадки — коллапсированная
  определённость из прошлого); при синхронизации и познании становится зоной
  контроля (детали — «Квантовые подписки»).
- **Личный у каждого**: даже без плана есть предположения, свои циклы, ритмы,
  свой горизонт планирования (ср. «Личный предикт»).
- **Дальность — свойство**: разная дальность доступна разным
  эффектам/словам/акторам/ивентам и зависит от инертности предмета (инертное
  читается дальше, живое — ближе; предел — горизонт предсказуемости); мера
  ясности — День/Ночь (ср. «День и Ночь»).
- **Квантовые подписки**: точки определённых предположений в предикте —
  ощущаются чуйкой (свойства — «Квантовые подписки», «Свойства подписок»).
- **Прецеденты → возможности**: выборка переходит в предикт по прецедентам
  (один раз — случайность, несколько — закономерность); прецедент не подписка,
  он возможность.
- **Борьба за будущее идёт на предикте** (ср. «Борьба за будущее»); при этом
  неминуемость подписки — свойство описания, не мира (ср. «Свобода и
  неминуемость»).
