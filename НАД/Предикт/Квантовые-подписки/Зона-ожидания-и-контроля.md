# Зона ожидания и зона контроля

**Статус:** рабочее.

Риалтайм + предикт — **зона ожидания** (холст): холст определён, якоря —
точки ожидания («молния — будет гром»; иные личные напыления — тоньше и
дальше) — во многом известны, но многое на холсте неявно и невидимо. Просадки
холста — определённость из прошлого (частично коллапсированные предсказания);
всё остальное неопределено. Зона ожидания постепенно вырисовывает симуляцию
грядущего — возможно, в квантовом вычислении вероятностей.

При достаточной синхронизации и познании зона ожидания становится **зоной
контроля**: можно удерживать свой вектор несмотря ни на что, уводить внимание,
воздействовать на других О по их предиктам (жёстко, но так). Чем меньше
условностей и больше огня — тем вернее получается (см. «Условности»).

## Влияние без понимания

- Для воздействия по предиктам **понимание не требуется**: достаточно карты
  консенсуса — кто какую версию держит, насколько устойчиво, где расходится с
  Хардом (инерция консенсуса; распределение швов — «Коллективная память»).
- Отсюда асимметрия: разгадать символ нельзя — перевод, растворивший чудо
  источника, убивает механику, а не понимает её («Протокол чтения источников»);
  а накрыть его консенсусную версию можно и без всякого понимания.
- Потому охват символов опаснее их разгадки: разгадка ограничена, охват — нет.
